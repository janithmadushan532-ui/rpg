# Subway Surfers – Swipe Only + 4 Worlds + Sinhala Science MCQ Power-ups

## Mobile controls (swipe only)
- Swipe left/right on the game canvas to change lanes.
- Swipe up to jump.
- Swipe down to slide.
- On-screen gameplay buttons and keyboard gameplay controls are disabled.
- During an MCQ, swipe movement is paused until the answer is completed.

## Worlds
The run advances through four worlds automatically:
1. City – first 250 distance units
2. Neon – 250 to 499 distance units
3. Jungle Temple – 500 to 749 distance units
4. Ancient Egypt – from 750 distance units onward

## MCQ Power-ups
- Jumping Boots, Flying Boost and Hoverboard are gated by a Science MCQ.
- Each answer displays feedback and a Sinhala explanation.
- Correct answers unlock the corresponding power-up.

## Notes
- This project is an adapted browser WebGL clone, not the official Subway Surfers game.
- Open `index.html` through a local web server / static hosting for correct asset loading.

## Sinhala Science Power-up Quiz Update

- Replaced the previous 14-item mixed-language quiz bank with 200 Sinhala MCQs.
- Grade 10: 100 questions across all 20 Grade 10 Science lessons (5 per lesson).
- Grade 11: 100 questions across all 15 Grade 11 Science lessons (6–7 per lesson).
- Each question contains four options, one correct option, a Sinhala explanation, grade and lesson metadata.
- Questions are assigned across the existing Jumping Boots, Flying Boost and Hoverboard quiz triggers.
- Incorrect answers reveal the correct answer and explanation and allow another attempt; correct answers unlock collection.
- Preserved the existing game worlds, assets, sound files and swipe-only gameplay controls.

Curriculum reference: the Sri Lanka Ministry of Education e-Thaksalawa Grade 10 Science course (20 lesson units) and Grade 11 Science course (15 lesson units). The question bank follows the lesson structure published on those official course pages; it is aligned to the textbook structure available there and is not a separate certification of any later revised syllabus edition.

- Grade 11: https://e-thaksalawa.moe.gov.lk/lcms/course/view.php?id=437&lang=si
